# Grocery RFQ WhatsApp Runtime

Buyer example:

`Grocery: rice 5kg, oil 1L, sugar 2kg`

Seller reply format:

`GQUOTE 12 rice=300, oil=150, sugar=90, delivery=30`

Buyer comparison command:

`Grocery Quotes`

The runtime only activates on explicit grocery/kirana prefixes so normal universal product/job/service capture remains unaffected.
